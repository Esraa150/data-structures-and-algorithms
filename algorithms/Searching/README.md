# Searching Algorithms

Basic searching algorithms implemented in C++.

### Linear Search

Searches for an element by checking each element sequentially.

* Works on unsorted arrays
* Returns the index of the first occurrence
* Best Case: O(1)
* Worst Case: O(n)
* Space Complexity: O(1)

### Binary Search

Searches for an element by repeatedly dividing a sorted array into two halves.

* Requires a sorted array
* Returns the index of the found element
* Best Case: O(1)
* Worst Case: O(log n)
* Space Complexity: O(1)
